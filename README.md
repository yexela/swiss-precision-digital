# Swiss Precision Digital

Build a premium boutique IT agency website for a Zurich-based software development studio with a Swiss-based Project Director (Yana Maletska) and senior offshore engineering team.

Key specifications and sections:
- Design & Aesthetic: Dark editorial aesthetic inspired by Linear and Vercel. Dark background (#08090A), indigo accent (#6366F1), crisp off-white text (#FAFAFA), subtle borders (#27272A), clean technical typography (Geist/Inter style), subtle grid patterns, abstract geometric accents, and micro-animations. Dark mode only.
- Navigation: Sticky header (transparent on hero, solid backdrop blur on scroll), logo, navigation links (What we build, How we work, About, Start a project), and full-screen mobile menu.
- Hero: Full viewport height, top badge "● Zurich, Switzerland — accepting new projects", headline "We ship products. Not decks.", subheadline highlighting senior developers and Swiss oversight, primary CTA [Start a project →] and ghost CTA [See our work], plus 3 trust metrics (12+ Years delivery experience, Senior devs only 5+ yr avg, Zurich-based accountability).
- Manifesto: Editorial large numbered typography (01, 02, 03 statements) with the positioning statement on boutique quality plus offshore speed.
- What We Build (Services): 3 large interactive cards with modern outline icons, descriptions, and tech pill tags for Mobile Development, Software & Web Platforms, and DevOps & Cloud Infrastructure.
- How We Work: 6 core delivery principles in a 2-column grid (Senior hands only, One point of contact in Zurich, You see progress weekly, Architecture before code, Swiss delivery standards, We stay until it ships).
- The Zurich Advantage: Two-column comparison explaining why Zurich oversight matters vs. why the development team is offshore, tied together with "Best of both worlds."
- Founder / About: Yana Maletska profile (Founder & Project Director, Zurich), bio covering 12 years delivering complex programmes at Meta (Oculus VR), Atlassian, and Pilatus Aircraft, previous company logos row, and LinkedIn link.
- Tech Stack: Responsive clean grid of muted technology tags/logos across mobile, web, backend, cloud, and DevOps.
- Start a Project (Contact): Interactive project inquiry form with name, email, company, project description, budget select, timeline select, send action, success state/toast, and Swiss contact metadata.
- Floating Action & Utilities: Floating bottom-right "Book a free call →" button modal/link, GDPR cookie banner, footer with Swiss registration copy, and proper SEO metadata.
